Command deck

Every command you need to set up, run, and customize the LSTM stock-forecasting pipeline — copy and paste straight into your terminal, in order.

01

Setup

Unzip the project, move into it, and install the four required packages. No GPU, no TensorFlow, no API keys.

Unzip and enter the project
$ unzip stock_lstm_forecasting.zip
$ cd stock_lstm_forecasting
Install dependencies
$ pip install -r requirements.txt
No internet needed. The repo ships with a bundled sample dataset (data/sample_stock_data.csv), so you can run everything offline.
02

Run the pipeline

One command runs preprocessing, training, evaluation, and plotting end to end with sensible defaults (60-day window, 32 hidden units, 60 epochs).

Train + evaluate with defaults
$ python main.py
Takes roughly 20–30 seconds on a laptop CPU. Watch for the epoch loss printout, then the final MAE / MSE / RMSE / MAPE summary.
Regenerate the synthetic dataset (optional)
$ python data/generate_synthetic_data.py
03

Customize hyperparameters

Every stage of the pipeline is controlled with CLI flags on main.py — no code edits required.

flagdefaultwhat it controls
--csvdata/sample_stock_data.csvInput OHLCV CSV path
--window60Days of history per training sample
--hidden32LSTM hidden units
--epochs60Training epochs
--batch_size32Mini-batch size
--lr0.005Adam learning rate
--test_ratio0.2Fraction of data held out (chronological)
--outdiroutputsWhere plots / metrics / weights are saved
Bigger model, longer training
$ python main.py --hidden 64 --epochs 100 --lr 0.003
Shorter lookback window, smaller test split
$ python main.py --window 30 --test_ratio 0.15
Save results to a separate folder
$ python main.py --outdir outputs_run2
04

Swap in real market data

Optional — requires internet and the yfinance package (already in requirements.txt). Pulls real OHLCV history from Yahoo Finance for any ticker.

Download real history for a ticker
$ python data/download_data.py --ticker AAPL --start 2015-01-01 --end 2025-01-01
Train on the downloaded file
$ python main.py --csv data/stock_data.csv
Try a different ticker, e.g. Tesla
$ python data/download_data.py --ticker TSLA --out data/tsla.csv
$ python main.py --csv data/tsla.csv

06

Check your outputs

After any run, these commands open or print what got generated.

Print the metrics file
$ cat outputs/metrics/metrics.json
List generated plots
$ ls -la outputs/plots/
Open the prediction chart (macOS / Linux)
$ open outputs/plots/predictions_vs_actual_test.png # macOS
$ xdg-open outputs/plots/predictions_vs_actual_test.png # Linux
